## 👋 About This Repository

This repository documents my journey learning and practicing **Tableau** through 30 practical dashboard projects.

Rather than creating dashboards only to practice the software itself, my goal was to progressively improve my ability to:

* 📊 Transform data into meaningful visualizations

* 💡 Communicate insights clearly

* 📈 Build dashboards that are useful for decision-making

Each dashboard represents another step in that learning process.

## 🔍 How I Approach a Dashboard

Whenever possible, I follow a simple analytical process:

### 01 — Understand the Data

What does the dataset represent?

### 02 — Define the Question

What are we actually trying to understand?

### 03 — Choose the Metrics

Which KPIs or measurements answer the question?

### 04 — Visualize

Which chart communicates the information most effectively?

### 05 — Analyze

What patterns, differences, or anomalies appear?

### 06 — Communicate

How can the dashboard make the insight easy to understand?
